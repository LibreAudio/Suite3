# Libre Audio Suite


## A toolbox of beautiful sounding free and open source audio plugins.
## Made for content creators, musicians and professional sound engineers.

20+ processors sharing one interface language. Every plugin features an Easy mode — a handful of controls that just work — and unfolds into Expert mode when you want the whole engine.

Created with ♥ in Berlin by experienced mastering engineers and audio developers.
